# Технические задания

Эта папка содержит backlog реализации и принятые решения по AI PC Guardian.
Перед началом разработки каждый этап получает отдельное сфокусированное ТЗ.

## Значения статусов

- **Запланирована** — границы и критерии приёмки зафиксированы, реализация не
  начата.
- **В работе** — код реализуется или проходит ревью.
- **Реализована** — код и тесты присутствуют; оставшиеся проверки на отдельных
  платформах явно перечислены.
- **Проверена** — Definition of Done выполнен на всех обязательных платформах.

но не должны отвлекать от первого локального клиент-серверного пути.

## Правила для следующих задач

Каждое ТЗ должно определять:

- один конкретный результат;
- публичные интерфейсы и контракты данных;
- затрагиваемые файлы и CMake-targets;
- правила валидации и обработки ошибок;
- тесты и критерии готовности;
- явные ограничения задачи, чтобы не расширять MVP случайно.

Статус задачи и корневой README обновляются в том же коммите, что и реализация.
